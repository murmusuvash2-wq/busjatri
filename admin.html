ℹ How it works

• Bus time fix: aapki changes data/time-overrides.json mein jaati hain — ek chhoti file. Site ka runtime patch (js/time-overrides.js) use har page load pe apply karta hai. Monday auto-rebuild inhe permanently data mein merge kar deta hai.
• Reports: users ke time reports data/time-reports.json mein aate hain (Google Form se, har 3 ghante).
• Blog: posts blog/ folder mein directly save hoti hain, manifest ke saath.
• Safety: har change ek GitHub commit hai — kuch galat ho to repo history se revert ek click.
• Ye page busjatri.in/admin.html pe hai lekin token ke bina koi isse kuch nahi kar sakta.
