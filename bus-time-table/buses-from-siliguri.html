Which places can I go from Siliguri Bus Stand by bus?

From Siliguri Bus Stand you can travel to Cooch Behar, Jalpaiguri, Islampur, Darjeeling, Esplanade, Kalimpong and others — the full destination list with bus counts is on this page.

Which operators run buses from Siliguri Bus Stand?
