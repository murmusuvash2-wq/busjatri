What is the first bus from Barasat to Medinipur?

What is the last bus from Barasat to Medinipur?
The last departure listed is at 4:00 PM — SBSTC Medinipur-Barasat (SBSTC). No later direct bus is listed on BusJatri for the same day, so plan accordingly.
Which operators run buses from Barasat to Medinipur?

How many buses run from Barasat to Medinipur?
