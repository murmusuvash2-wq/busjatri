# scripts/

Grouped by what the script does, not by when it was written. Target: fold ~230 files
(incl. ~100 one-shot `patch_*.py`) down to ~30 real scripts.

| Folder | What |
|---|---|
| `add/` | bus-add system |
| `dedup/` | duplicate-check system |
| `enrich/` | stoppages, fare, time |
| `geo/` | geocode + polygon |
| `generate/` | route, stand, via, operator, blog, place page generators |
| `content/` | About-the-route generator |
| `seo/` | clean-urls, legal-links, consent, meta, sitemap, robots |
| `reports/` | user reports |
| `validate/` | schema + quality checks |
